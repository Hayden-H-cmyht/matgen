# matgen · 材质贴图生成器（线上版）

纯浏览器端运行的**无缝可平铺 PBR 材质生成工具**：9 种建材材质（木纹/大理石/花岗岩/砖墙/混凝土/抹灰/草地/沙地/金属）× 6 种做旧效果（污渍/苔藓/裂纹/磨损/划痕/褪色），全部在本机浏览器里实时计算，**不上传任何数据、离线可用**。

- 3×3 平铺预览 / PBR 五通道查看 / WebGL 实时光照预览（球体+地面）
- 照片 → 无缝 PBR（本地上传，不出浏览器）
- 一键下载 ZIP：albedo / normal / roughness / height / ao + obj/mtl，3D 建模渲染直用

桌面端与命令行批量版见主项目（D:\\zcode\\matgen，含 numpy 批量与 AI 生图接口）。
